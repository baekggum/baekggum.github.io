# 김현민 · Personal profile

프론트엔드 개발과 웹 보안, 프로젝트·연구·학습의 기록을 담은 개인 소개 페이지입니다.

사이트: https://baekggum.github.io

## 로컬 실행

```sh
python3 -m http.server 4317 --bind 127.0.0.1
```

http://localhost:4317 에서 확인할 수 있습니다.

## 수정 및 배포

소개 내용은 `index.html`에 직접 저장됩니다. 스타일은 `style.css`, 다크 모드·섹션 이동·이메일 복사는 `app.js`에서 관리합니다. 별도 설치나 빌드가 필요 없습니다.

GitHub Pages는 `main` 브랜치의 저장소 루트에서 배포됩니다. 수정 사항을 커밋하고 push하면 자동 반영됩니다.

이 저장소에는 공개용 페이지 파일만 보관합니다. 인증 정보, API 키, `.env`, 로컬 설정이나 배포 자격 증명을 추가하지 마세요.
